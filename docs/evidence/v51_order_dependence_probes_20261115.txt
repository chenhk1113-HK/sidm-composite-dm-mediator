draws come from the process's global numpy state unless rstate is supplied. In an unseeded
test, "which tests ran earlier in the same pytest process" is an input to the assertion.

and every sampling call inside the sampler threads self.rstate (sampler.py:475-549). Grepping the
package for direct global draws (`np.random.random|uniform|normal|choice|rand`) returns nothing,
so rstate is the only random source -- i.e. supplying it fully determines the sampler.

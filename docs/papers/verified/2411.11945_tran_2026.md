## Profile it proposes

A four-free-parameter isothermal-core profile, called **T25** in its own Table I, compared against Read 2016 (R16), Read-2017/F24 (R17-F24) and the Yang+ 2023/2024 parametric form (Y23/Y24).

Raw extracted fragment of the Table I row (superscripts are lost in extraction — verify against the PDF before implementing):

> `ρT25  4ρc ( tanhr/r c r/rc )n ( 1 + (r/r′ s)2 )(3−n)/2 i−1 ρ∝r−n rc f−1(0.51/n)`

In words: ρ(r) = 4 ρ_c [f(r/r_c)]^n [1 + (r/r'_s)^2]^((3−n)/2) with f(x) = tanh(x)/x, γ = 2 fixed, n free, and the outer scale written as r'_s = c·r_200 (the paper re-expresses the NFW scale radius through the concentration). Core half-density radius ∝ f^-1(0.51/n).

## Verdict for the project

**methodology-caveat + usable profile family.** v19.2-F fits Cloud-9 with an NFW profile and quotes a 7σ (SIDM: 3σ) deviation from the concentration-mass relation. This paper is direct evidence that the *choice of profile family* changes fitted scale radii for cored halos, which is exactly the weak point of a "concentration deficit repaired by SIDM" claim.

## Key findings

Fits observational data in an **asymmetric SIDM model** using the cross sections computed in the companion paper [9], which incorporate **both t-channel and u-channel** exchanges for identical-particle scattering. Reports **good fits from dwarf galaxies to galaxy clusters**, corresponding to relative velocities from **~20 km/s to >10^3 km/s**, and compares against earlier fits that used t-channel exchange only.

This is the paper the draft's L90 sentence describes as *"structurally similar but using a different UV-completion story"* — a dark-photon (vector-mediator) model spanning roughly two decades in velocity.

## What the paper actually claims (paraphrase, not quote)

1. Cloud-9 (a Reionization Limited H I Cloud near M94, discovered by FAST) has **no optical counterpart** and negligible stellar content, so it is a clean probe of the underlying DM density profile free of baryonic-feedback complexity.
2. The observed H I column-density profile is **consistent with BOTH** a cuspy NFW (CDM) halo and a cored (SIDM) halo. The NFW fit is a good fit within observational uncertainties.
3. The data therefore do **not** discriminate CDM from SIDM on the profile shape alone. What they constrain is the **concentration**: the halo must be exceptionally diffuse.
4. For CDM, the required concentration is **7σ below** the cosmological c-M relation (7.3σ posterior peak, >6.7σ even allowing for fit uncertainty) — i.e. CDM needs an anomalously low-concentration halo.
5. For SIDM, core formation **alleviates** that tension: at σ/m = 50 cm²/g the preferred halos are only ~3σ below the cosmological median; the marginalized SIDM concentration posterior peaks at 3.3σ below.
6. There is a **characteristic degeneracy** between halo concentration and the stage of gravothermal evolution: halos at different τ produce nearly identical H I profiles, so the profile alone cannot pin down either. The degeneracy is broken only by the cosmological c-M prior, which is what makes the deviation diagnostic.
7. Cloud-9 analogs are identified in the Concerto suite of velocity-dependent-SIDM zoom-in simulations, suggesting RELHICs are a promising new probe of DM self-interactions.

## The "3.2σ" figure — precise provenance (v40.61 clarification)

The project's "Ohana+ 2026 3.2σ" is **correctly attributed**, and the exact chain is:

> The **3.2σ** is the deviation-below-cosmological-median for the **SIDM τ = 0.18 best-fit halo** (M_200 = 4.7 × 10⁹ M☉, c_200 = 4.0), from §3.1, with σ/m = 483 cm²/g inferred via Eq. 8.

It is **NOT** the CDM figure (that is 7σ / 7.3σ) and **NOT** the marginalized SIDM peak (that is 3.3σ). The project script `scripts/ohana2026_cloud9_joint_likelihood.py` encodes exactly this fiducial:

```python
M_200_true = 4.7e9
c_200_true = 4.0
tau_true = 0.18
# "3.2 sigma below cosmological median concentration (Diemer+ 2019)."
# "Inferred sigma/m: 483 cm^2/g (Ohana+ Eq. 8)."
```

**⚠ Framing correction (v40.61):** the report's §1 previously called this the "Ohana+ 2026 **upper limit**". That is a mischaracterisation. Ohana+ 2026 is a **posterior inference of the concentration deviation** for a specific halo model, not a published upper limit on anything. The project compares its own posterior against that inference, which is why `test_ohana2026_baseline.py::test_ohana2026_published_in_68CI_unchanged` asserts `published_in_68CI == False` (the project's 1.04σ median does not contain the published 3.2σ in its 68% CI — an honest "FAILED VALIDATION" verdict, deliberately locked).

## Caveats relevant to the project

- **The 3.2σ is a τ-dependent, model-dependent number.** It is quoted for one specific SIDM best-fit (τ = 0.18). The paper's own marginalized value is 3.3σ, and the deviation varies continuously with the fixed σ/m in the sweep (Fig. 4). Comparing the project's tension against "3.2σ" without stating which branch is compared is under-specified.
- **The scatter assumption is load-bearing:** 0.16 dex (Diemer & Joyce 2019). The σ-deviation scales as (log c_deviation)/0.16, so a different scatter assumption changes the σ values directly.
- **The c_200 degeneracy is the paper's central caveat.** Because the fit loses sensitivity to c_200 once the core is large enough to encompass the data (Eq. 7 has no c_200 dependence in that limit), the concentration is constrained **only** through the cosmological prior. A project result that moves c_200 is therefore moving a quantity the paper's likelihood is nearly blind to.
- **Stability screening is applied** (dM_gas/dρ_c > 0). Solutions violating it are excluded from the inference. A project model that does not implement this screening is not strictly comparable.

# Elbert+ 2015 — Core formation in dwarf haloes with SIDM

**Status:** ✅ VERIFIED 2026-10-19 (downloaded + read for v40.42 c-tau prescription)

**arXiv:** 1412.1477v1
**Authors:** O. D. Elbert, J. S. Bullock, S. Garrison-Kimmel, M. Rocha, J. Oñorbe, A. H. G. Peter
**Year:** 2015 (MNRAS 453, 29)
**Local PDF:** `docs/papers/verified/1412.1477_elbert_2015.pdf` (6.2 MB)

## Key Findings

1. **σ/m range for TBTF alleviation:** σ/m ∈ [0.5, 50] cm²/g produces cores of 300-1000 pc
2. **Largest, lowest-density cores at σ/m = 5-10 cm²/g** (sweet spot for SIDM core formation)
3. **At σ/m = 50 cm²/g, halos show "mild core-collapse behavior" but still retain constant-density cores** — c_200 stays close to NFW value
4. **V_max scale ~ 40 km/s** (dwarf scale, not cluster scale)
5. **Conclusion:** A wide range of σ/m values (2 orders of magnitude) can produce cores — no fine-tuning needed

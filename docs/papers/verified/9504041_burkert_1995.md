## CORRECTION to this project's own record

Registry §7.11 D4 previously stated "**No arXiv preprint exists for it**". That was **wrong**. `astro-ph/9504041` is the preprint of this paper: Unpaywall maps DOI 10.1086/309560 to `https://arxiv.org/pdf/astro-ph/9504041` and Semantic Scholar lists `externalIds.ArXiv = astro-ph/9504041` for the same DOI. The wrong link the user's `Useful papers.docx` supplied was `astro-ph/9508181`, which does not exist. **Do not re-import that id.**

A second, related correction (registry §7.11 D8): the draft refers five times to a "**Burkert+ 2020** c-τ prescription" and asserts no such paper was found. A 2020 Burkert paper **does exist** — A. Burkert, "Fuzzy Dark Matter and Dark Matter Halo Cores", ApJ **904**, 161 (2020), doi:10.3847/1538-4357/abb242 (Crossref + OpenAlex verified, vol 904 issue 2 page 161) — but it is a **fuzzy-DM** core paper and provides **no SIDM c-τ concentration fit**. The recommendation as named cannot be implemented; the framework already superseded it with Sameie+ 2020.

## Key results used by the project

| Claim | Verbatim / near-verbatim support | Where |
|---|---|---|
| Dwarf halos form a **one-parameter family with self-similar density profiles** | "the dark matter halos of dwarf spiral galaxies represent a one-parameter family with self-similar density profiles" | abstract |
| Their global parameters obey **simple scaling relations** explainable in standard CDM **if all halos formed from density fluctuations with the same primordial amplitude** | "The observed global halo parameters are coupled with each other through simple scaling relations which can be explained by the standard cold dark matter model if one assumes that all the halos formed from density fluctuations with the same primordial amplitude" | abstract |
| **Finite central densities correlate with the other global parameters**, which **rules out** cores created later by baryonic dynamics | "We find that the finite central halo densities correlate with the other global parameters. This result rules out scenarios where the flat halo cores formed subsequently through violent dynamical processes in the baryonic component." | abstract |
| The halo profile is an **isothermal-like cored profile** with a **core radius r_c** and a **finite central density ρ_0**, falling as ~1/r² outside the core | "where r_c is the core radius and ρ_0 is the central dark matter density"; "the isothermal density profile becomes almost constant at radii smaller than r_c and has a finite central density" | eq. (1) region (formula glyphs garbled in the extract) |
| CDM simulations instead predict a **cusp** diverging as ~1/r | "the numerical models indicate a density distribution which diverges as ... in the inner parts, leading to an infinite density in the center" | §1 |

**Not quotable from this extract:** the numeric value of the central-density floor, the core-radius numbers, and the scaling-relation exponents in eq.

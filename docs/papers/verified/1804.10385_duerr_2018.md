## Key findings

Light vector mediators naturally induce **velocity-dependent** DM self-interactions while still allowing the correct relic abundance via thermal freeze-out. But if those mediators decay into Standard-Model states (electrons or photons), the scenario is **robustly excluded by Cosmic Microwave Background constraints**.

The paper asks how far this conclusion can be evaded if the vector mediator is **stable** and therefore contributes to the DM density while annihilating into lighter degrees of freedom. It finds **viable parameter space** giving the desired self-interaction cross section to address the small-scale problems, while remaining compatible with **CMB and Big Bang Nucleosynthesis** bounds.

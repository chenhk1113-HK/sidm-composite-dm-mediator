## Key result (verbatim from abstract)
> "Applying this method to a gold sample of eleven cluster mergers hosting symmetric double radio relics, we determine a 68% upper limit on the SICS of σ/m < 0.22 cm² g⁻¹. This is the first constraint from cluster collisions that fully marginalizes over mass uncertainty, viewing angle, collision speed, merger phase, impact parameter, and gas profile slope."

## 95% upper limit
σ/m < 0.63 cm²/g (per M3 verification, from body of paper)

## Method
- 11 cluster mergers with symmetric double radio relics
- Shock-to-shock distance as merger chronometer
- 576 hydrodynamic simulations with GIZMO code
- Bayesian inference (emcee MCMC)
- Mass grid: M₂ ∈ {0.1, 1, 5, 10} × 10¹⁴ M☉
- Velocity: ⟨v_pair⟩ ~ 1500 km/s (cluster-scale)

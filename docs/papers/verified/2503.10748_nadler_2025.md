## Key findings

Presents **SIDM Concerto**: 14 cosmological zoom-in simulations in CDM and SIDM, built on the Symphony and Milky Way-est suites. The set covers one LMC-mass system (~10^11 M_sun host), two Milky Way analogs (~10^12 M_sun), two group-mass hosts (~10^13 M_sun) and one low-mass cluster (~10^14 M_sun). Each host has ~2 × 10^7 particles and is run in CDM plus one or more **strong, velocity-dependent SIDM** models.

Analysis of SIDM (sub)halo populations across seven subhalo mass decades gives core-collapse fractions and density-profile statistics.

## Key numbers

- **14** zoom-in simulations; CDM + one or more strong velocity-dependent SIDM models
- Host masses: ~10^11 (LMC-mass), ~10^12 ×2 (MW analogs), ~10^13 ×2 (groups), ~10^14 M_sun (low-mass cluster)
- **~2 × 10^7 particles** per host
- Analysed over **seven** subhalo mass decades
- Why it matters to the draft: it is **single-component**, so it cannot be cited as support for a heavy-fraction (two-component) picture

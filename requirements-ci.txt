# requirements-ci.txt — what CI installs to run the test layer.
#
# Deliberately narrower than the root requirements.txt, for one reason: the root
# file pins WIMpy==1.1.1 and PyPI has no such version (published releases are
# 0.2 - 0.6). A job that installs the root file dies at the install step.
#
# WIMpy is not needed to run the suite: every test that touches it imports it
# lazily inside the test body, and the 15-layer gate runs the whole suite on an
# interpreter where it is absent (verified 2026-11-03: importlib.util.find_spec(
# 'wimpy') is None, and the layer still reports 1954 passed / 22 skipped /
# 36 deselected).
#
# Everything else is pinned to the same versions as the root file so CI and the
# local gate resolve identical dependencies. All pins below were confirmed to
# exist on PyPI on 2026-11-03.

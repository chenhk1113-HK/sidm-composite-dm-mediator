# T135 — T134 v2 Retraction: Circular Reasoning + Misread CFT 2021 (2026-09-20)

## What went wrong

User requested a thorough recheck of T134 v2 (the "CFT 2021 quantitative
match" claim). The recheck found **TWO major errors**:

### Error 1: Circular reasoning

The data in `sigma_m_phase44.json` is generated by:
- `Snakefile:phenomenology_curves` rule
- Calls `t120_4_joint_fit.py:joint_fit_full_evaluation(a_slope_override=1.0)`
- Uses `yukawa_bg(v, sigma_0, a_slope=1.0, v_ref=100)` which is exactly v^(-1)

So:
1. We set a_slope=1.0 as input parameter
2. The data has slope = -1.0 by construction
3. We fit the data and "discovered" slope = -0.986 (essentially -1.0)
4. We declared: "CFT α=0.246 matches within 0.4%"

This is **circular**: we proved our data has the slope we put in.

**Verification**: Running `joint_fit_full_evaluation(a_slope_override=2.0)`:
- Low-v recovered slope = -1.998 (essentially -2.0)
- Same fit logic, just with different input

So the "CFT α=0.246" was an artifact of using a_slope=1.0 input.

### Error 2: Misread CFT 2021 parameter range

CFT 2021 (arXiv:2102.05674) explicitly states:

> "Bulk mass: 1/2 ≤ α ≤ 1 (Calculability, unitarity)"
> "we further restrict the range to α ≥ 1/2 to avoid the regime where
> the long-range potential is steeper than the centrifugal term"

So CFT 2021's valid parameter range is α ∈ [0.5, 1.0], NOT [0, 1.0].

For α = 0.5: σ_T ~ v^(-2.0) (standard Born)
For α = 1.0: 4D single mediator (Yukawa)

α = 0.25 (which I claimed matched) is **outside the valid range**.
Even if our data had been independent, α = 0.25 wouldn't be a CFT 2021
prediction.

## What this means for our claims

**Wrong claims (must retract)**:

- For our data to fit CFT 2021, we'd need slope in [-2.0, -4.0]
- Our slope ≈ -1.0 doesn't fit CFT 2021's valid parameter range

**Three of the five T90.57 channels use Gaussian approximations on σ/m. None of them have public raw posterior chains available, and substituting chains would require either author collaboration or digitizing published 1D posteriors.** The Gaussian approximations are NOT placeholders for missing data — they encode published central values + 1σ widths from the source papers. The audit's recommendation is to either (a) contact authors for chains, (b) digitize published posteriors, or (c) document why Gaussians are the best available.

## Channel-by-channel audit

### Channel 1: Cloud-9 (RELHIC)

**T90 code:** `t90_v51_resonant_joint_fit.py:67-73`

```python
_CLOUD9_LOG_CENTER = np.log10(np.sqrt(30.0 * 500.0))  # = 2.19
_CLOUD9_LOG_WIDTH = (np.log10(500.0) - np.log10(30.0)) / 2.0  # ~0.61

def loglike_cloud9(sigma_m_c9):
    if sigma_m_c9 <= 0:
        return -np.inf
    log_sm = np.log10(sigma_m_c9)
    z = (log_sm - _CLOUD9_LOG_CENTER) / _CLOUD9_LOG_WIDTH
    return -0.5 * z * z
```

**Source data:** arXiv:2608.04362 (RELHIC / Cloud-9). Single published constraint: σ/m(28 km/s) ∈ [30, 500] cm²/g.

**Treatment:** Gaussian in log10(σ/m) with center at geometric mean and width chosen so the 1σ range covers the published bounds. This is a 2-parameter encoding (center, width) of a 2-bound constraint.

**Are real posterior chains available?**

Searched for: "RELHIC Cloud-9 SIDM posterior chain", "arXiv:2608.04362 chains", "Yang 2026 SIDM posterior".
Result: arXiv:2608.04362 is published; no public MCMC dump. The paper presents its result as a 1D constraint on σ/m at v=28 km/s, not as a posterior. There is no chain to download.

**Alternative:** The constraint could be reformulated as a half-Gaussian (1-sided) rather than a 2-sided Gaussian. The current 2-sided Gaussian gives the same value at σ/m=30 as at σ/m=500, which is correct for a "preferred range" but does not penalize σ/m > 500 (where the model is likely wrong). This is a minor refinement, not a chain replacement.

**Verdict:** Gaussian is the best available. The 2-sided Gaussian encodes the published "preferred range" faithfully.

### Channel 2: Galactic dSph / UFD

**T90 code:** `t90_v51_resonant_joint_fit.py:76-84`

```python
_GAL_UPPER_LIMIT_LOG = np.log10(2.0)  # 0.301
_GAL_UPPER_SIGMA_DEX = 0.3

def loglike_galaxy(sigma_m_gal):
    if sigma_m_gal <= 0:
        return -np.inf
    log_sm = np.log10(sigma_m_gal)
    if log_sm <= _GAL_UPPER_LIMIT_LOG:
        return 0.0
    z = (log_sm - _GAL_UPPER_LIMIT_LOG) / _GAL_UPPER_SIGMA_DEX
    return -0.5 * z * z
```

**Source data:** Hayashi et al. 2025, arXiv:2503.13650. Published: σ/m_0 < 0.2 cm²/g at 95% CL from combined analysis of 8 classical + 23 ultrafaint MW satellite galaxies (SASHIMI-SIDM).

**Treatment:** Half-Gaussian upper limit with σ = 0.3 dex. This is a "soft wall": below 2 cm²/g, no penalty; above, Gaussian penalty growing as 0.5 dex² per dex above the limit. The 2 cm²/g limit corresponds to the published "relaxed at V_50 = 18 km/s" value (the velocity-independent limit is 0.2 cm²/g; the v-dep relaxed value is 1.0 cm²/g; T90 uses 2 cm²/g as a conservative upper bound).

**Are real posterior chains available?**

Searched for: "Hayashi 2025 SASHIMI posterior", "arXiv:2503.13650 chains", "SIDM UFD posterior".
Result: arXiv:2503.13650 presents a 95% CL upper limit, not a posterior. The paper does not publish a chain.

**Alternative:** The 0.3 dex width is a "factor-of-2 tolerance" choice by the project; it is NOT the published 95% CL width. A real posterior chain would give the actual width at 95% CL.

**Verdict:** Half-Gaussian is the best available. The 0.3 dex width is a project choice, not published; documentation should note this.

### Channel 3: Bullet Cluster

**T90 code:** `t90_v51_resonant_joint_fit.py:87-95`

```python
_BUL_UPPER_LIMIT_LOG = np.log10(0.5)  # -0.301
_BUL_UPPER_SIGMA_DEX = 0.3

def loglike_bullet(sigma_m_bul):
    if sigma_m_bul <= 0:
        return -np.inf
    log_sm = np.log10(sigma_m_bul)
    if log_sm <= _BUL_UPPER_LIMIT_LOG:
        return 0.0
    z = (log_sm - _BUL_UPPER_LIMIT_LOG) / _BUL_UPPER_SIGMA_DEX
    return -0.5 * z * z
```

**Source data:** Cha+ 2025 (Bullet Cluster re-analysis). Default: σ/m(3000 km/s) < 0.5 cm²/g. Alternative: σ/m < 0.613 cm²/g (O'Donnell+ 2026, arXiv:2508.20179, from MACS J0138-2155 single cluster).

**Treatment:** Half-Gaussian upper limit, same structure as Galactic.

**Are real posterior chains available?**

Searched for: "Cha 2025 Bullet SIDM posterior", "arXiv:2508.20179 chains".
Result: Bullet Cluster constraints are typically published as upper limits (95% CL), not full posteriors. O'Donnell+ 2026 publishes a 95% CL upper limit. No chains available.

**Alternative:** None. The constraint IS an upper limit; a chain would be a uniform distribution above the limit (uninformative).

**Verdict:** Half-Gaussian is the only sensible encoding of an upper limit. This is the canonical treatment for σ/m upper-limit constraints in the literature.

**Are real posterior chains available?**

KSFR is a THEORETICAL constraint derived from chiral perturbation theory, not an observational posterior. There is no chain to replace; the validity box is a hard theoretical bound.

**Verdict:** Hard mask is the correct treatment. There is no observational posterior to substitute.

## Honest assessment

**The reviewer's recommendation (#4 in the 2026-09-11 review) is sound in principle but misframes the situation.** The Gaussian likelihoods are NOT placeholders for missing data — they ARE the published constraints, encoded in the standard parametric form. There is no "real posterior chain" to substitute because the source papers (Hayashi+ 2025, Cha+ 2025, RELHIC) publish their results as constraints with 95% CL bounds, not as posterior distributions.

The way to honor the reviewer's intent (more rigorous uncertainty propagation) is one of:

**Option A — Author collaboration.** Contact Hayashi, Cha, RELHIC authors for unpublished MCMC chains. Probability of success: ~30% (academic incentives favor publication, not chain sharing). Time: 2-6 weeks.

**Option B — Digitize published posteriors.** Extract 1D marginalized posteriors from published figures using `webdigitizer` or similar tools. Probability of success: ~80%. Time: 1-3 days per paper. Caveat: digitizing a 1D posterior loses the joint shape information.

**Option C — Document the Gaussian encoding.** Add explicit citations + sensitivity tests to the project docs. Probability of success: 100%. Time: 1-2 days. This is the "document why Gaussian is the best we can do" branch of the original TODO.

**Option D — Hybrid: digitize (B) where possible, document (C) where not.** Probability of success: ~90%. Time: 1 week. Most defensible.

**My recommendation: Option D, executed after the 2026-09-08 pause directive is lifted.** Per the pause, "wait for new evidence and datasets" — chain availability is exactly such an external dependency. Re-running T90.57 with new chains without first validating them via Option D would be premature.

## Lessons learned

1. **"Replace Gaussian with raw chain" is a misframe when the source is an upper limit.** A Bullet Cluster upper limit IS a half-Gaussian; that's the canonical encoding. The recommendation applies to channels where the source IS a posterior (e.g. SPARC rotational curves, if those are encoded as Gaussians).

2. **Audit scope matters.** Auditing all 26 channels in `channels_extended.py` would have produced a much longer document with mostly "no change needed" verdicts. Scoping to T90.57's actual 5 channels took 30 minutes and produced a sharper result.

3. **Hard masks are not approximations.** The KSFR channel is a theoretical constraint, not a statistical one. Treating it as a Gaussian would be a category error.

## T60 — Chiral log corrections

The PCAC relation m_π² = 2 m_q Λ_dark / N_dark has a chiral log correction:

  m_π² → m_π² (LO) × (1 + (1/N_f) × log(Λ_dark / m_π))

For typical (Λ_dark ~ 100 MeV, m_π ~ 50 MeV), correction is **30-50%**. At T54's MAP (Λ_dark = 0.15 MeV), the log diverges (since Λ_dark < m_π).

**Implication**: the T54 best-fit is in a regime where PCAC breaks down. A proper treatment requires non-perturbative chiral Lagrangian.

## T62 — LZ direct detection

Direct-detection cross-section for the dark rho model:

  σ_DM_n = ε² × (m_DM × m_n / (m_DM + m_n))² / m_φ⁴

For T54 best-fit (m_DM = 34 GeV, m_φ = 3.5 MeV, ε = 10⁻⁵⁷):
  σ_DM_n = 2.0×10⁻¹³² cm²
  LZ SR1+SR3 limit: 1.1×10⁻⁴⁷ cm²
  **Gap: 85 orders of magnitude**

The model is **invisible** to direct detection. To detect, ε would need to be 10⁻¹⁵ — **42 orders of magnitude above the T54 posterior**.

## T63 — Dark rho decay modes

The dark rho decay depends on which channels are open:

| Configuration | Decay mode | BR |
|---|---|---|
| m_π > m_ρ/2 (closed) | SM via ε | BR_visible = 1 |
| m_π < m_ρ/2 (open) | Dark pions (invisible) | BR_invisible ~ 1 |
| m_ρ < 2m_e | No visible decay | BR_visible = 0 |

For T54 best-fit (m_ρ = 3.5 MeV):
- Below 2m_e threshold (1.02 MeV), so no visible decay allowed kinematically
- If m_π > 1.75 MeV: no invisible decay either → rho is STABLE on cosmological timescales
- If m_π < 1.75 MeV: invisible decay dominates

**At T54 parameters, the dark rho is essentially a stable DM particle, not a decay mediator.**
